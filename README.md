# SESCO

Sistema de gestión (Backend y Frontend).

## Tecnologías
- **Backend:** Python (FastAPI) + PostgreSQL
- **Frontend:** React (Vite)

## Instalación local
1. Clonar el repo: `git clone https://github.com/jhonn96/SESCO.git`
2. **Backend:** Entrar a `/backend`, crear entorno virtual, instalar `requirements.txt` y configurar el archivo `.env`.
3. **Frontend:** Entrar a `/frontend`, ejecutar `npm install` y luego `npm run dev`.
